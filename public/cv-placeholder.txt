CV PLACEHOLDER — BUKAN CV ASLI
================================

File ini adalah placeholder jujur: tombol "Unduh CV" di situs mengarah ke
berkas ini karena CV asli (PDF) belum tersedia.

Cara mengganti:
1. Siapkan CV Anda dalam format PDF, misalnya public/cv-aditya-pratama.pdf
2. Ubah nilai `cvPath` di lib/content.ts menjadi "/cv-aditya-pratama.pdf"
3. Hapus teks tombol "(Placeholder)" bila sudah final
4. Boleh menghapus file cv-placeholder.txt ini

Nama, metrik, pengalaman, dan seluruh data di situs ini juga placeholder
(lihat komentar "PLACEHOLDER" di lib/content.ts).
